# VISION

## What we're building
A **reusable, provider-agnostic glass-box agent platform** — the team's pre-built Buildathon foundation —
and two skins that ride on it:
- **Governance OS** (Lucky's personal flagship; evolves the deployed EvidencePack).
- **VisaPilot** (team project; grounded immigration copilot).

The platform is **the locked asset**. Skins are ~10–15% on top (corpus + tools + UI + workflow) — *but only
if the skeleton is continuously integrated end-to-end*; modules built in isolation make skins ~60% pain.
**VisaPilot is a prepared demo skin, not a locked event submission** — the event submission adapts to the
sponsor problem statement that drops on-site.

## Why
Buildathon judges and sponsors (Auger, Wand, Microsoft, Tavily, Featherless) reward **reliable, observable,
guardrailed agents** over flashy demos. Lucky's 4-yr resume is regulated AI (fraud, compliance, governance,
RAG, evals, human-in-the-loop). The platform showcases exactly that — and on June 18 we adapt it to the
given problem statement instead of building architecture under time pressure.

## What "done" looks like
- **Skeleton:** an integrated, deployed app where a request flows end-to-end through retrieval → reasoning →
  governance (citation verification, confidence, guardrails) → human-review gate → observability → evals.
  Swapping corpus/tools/UI produces a new vertical without touching the core.
- **Governance OS:** EvidencePack repositioned as a platform (registry, eval tracking, risk scoring, audit
  trail, evidence export) with a live link.
- **VisaPilot:** grounded copilot that cites official sources or refuses, with an eval dashboard.

## Non-goals
- Inventing novel algorithms or research. This is execution + reliability.
- Building the agent core inside no-code app builders.
- Single-track tunnel vision — any serious project spans multiple tracks.

## Success metrics
- Skeleton deployed and demoable before June 18.
- Event day: <10% time on architecture, >90% on adapting to the problem statement.
- Governance OS live + on resume/GitHub; VisaPilot demoable to the room.
